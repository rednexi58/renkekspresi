# Renk Ekspresi / Color Express

Slogan: **Doğru rengi seç. Son durağa yetiş!**

GitHub'a bu klasörün içeriğini yükleyin: `codemagic.yaml`, `ci/`, `Godot/` ve rehber depo kökünde yan yana olmalı. ZIP dosyasını tek başına kaynak diye yüklemeyin.

Oyun adı, oyun içi başlıklar, dosya/derleme adları ve Codemagic akışı yenilendi. Apple/Google Bundle ID `com.bedodrive.trainjam3d` ve yerel kayıt yolu mevcut kurulumla uyum için korundu. Oyun mekaniği v0.27 ile aynıdır.

İlk adımlar için TESTFLIGHT_ADIM_ADIM_TR.md dosyasını okuyun.

Bu bir kaynak/derleme paketidir; imzalı IPA değildir. StoreKit, gerçek reklam ve çevrimiçi scoreboard hâlâ bağlı değildir. Satın alma/reklam düğmeleri ücretsiz test simülasyonudur. Skor tablosu bu cihazdaki kişisel rekorları gösterir.
