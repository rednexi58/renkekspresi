# Renk Ekspresi: aynı uygulamada Unity TestFlight geçişi

Bu paket **imzalı IPA değildir**. `codemagic.yaml` Unity derlemez; Unity Build Automation tarafından üretilmiş **App Store dağıtımına imzalı IPA** dosyasını mevcut `Apple AppStore` entegrasyonuyla App Store Connect'e yükler. Godot iş akışının bir kopyası `ci/legacy_godot.yaml` içindedir. Bundle ID değişmez: `com.bedogames.renkekspresi`.

1. ZIP içindeki `codemagic.yaml` ve `ci/` klasörünü mevcut GitHub reposunun **kök dizinine** koy. Eski kök `codemagic.yaml` dosyasını değiştir. `Renk_Ekspresi_Unity/Assets/RenkEkspresi/Runtime/GameManager.cs` dosyasını da aynı yoldaki dosyanın üstüne koy. `Renk_Ekspresi_Unity` klasörünün kalanını ve Godot kaynaklarını şimdilik koru.
2. Unity Dashboard → DevOps → Build Automation → Configurations bölümünde mevcut GitHub deposundan **iOS** hedefi yapılandır. Proje alt yolu `Renk_Ekspresi_Unity`, Editor `6000.0.60f1`, build hedefi iOS, bundle ID `com.bedogames.renkekspresi`, sürüm `0.40.0` ve bu sürümde daha önce kullanılmamış pozitif bir build numarası olsun. WebGL hedefi ayrı kalır. Apple App Store **distribution** sertifikası ve aynı ID'ye ait provisioning profile ile imzalı IPA ürettir. Unity'nin iOS hizmeti için `.p12` + `.mobileprovision` yüklemesi gerekebilir; Codemagic'teki `Apple AppStore` API anahtarı, bu Unity imzalama dosyalarının yerini tutmaz.
3. Unity iOS build başarıyla tamamlanınca indirilen çıktının `.ipa` olduğundan emin ol. `.zip` veya yalnız Xcode proje klasörü ise bu yükleme akışına uygun değildir. Unity'nin indirme bağlantısı oturum açmayı gerektiriyorsa doğrudan Codemagic `curl` ile indirilemez; kalıcı/erişilebilir bir artifact URL veya kendi erişilebilir depolaman gerekir. İmzalı IPA'yı herkese açık repoya koyma.
4. Codemagic → mevcut Renk Ekspresi uygulaması → Environment variables: `UNITY_IOS_IPA_URL` isminde **Secret** değişkenine IPA'nın Codemagic tarafından erişilebilir indirme adresini gir. Mevcut `renk_ekspresi_ios` değişken grubunu ve `Apple AppStore` entegrasyonunu koru. Uygulamayı veya bundle ID'yi yeniden oluşturma.
5. Codemagic'de `Renk Ekspresi - Unity TestFlight` workflow'unu başlat. Önce IPA'nın içindeki ID, sürüm ve imza klasörü denetlenir. Yüklemeden sonra App Store Connect → **Renk Ekspresi → TestFlight → Builds** altında Apple işlemesinin bitmesini bekle ve iç test grubuna build'i seç. Dış test için Beta App Information ve inceleme iletişim bilgileri doldurulmalı.

**Sınırlar:** Bu ortamda Unity Editor/macOS imzalama hesabı veya IPA bulunmadığından iOS build ve cihaz testi yapılmadı. TestFlight'a bir Unity sürümü henüz yüklenmiş değildir. `GameManager.cs` değişikliği yalnız WebGL bulut build'inin mevcut `index.html` dosyasıyla bağlantıyı sınamasını sağlar. iOS hâlâ uzak uç noktayla bağlantı kontrolü yapar. Reklam, VIP satın alma ve gerçek çevrimiçi liderlik tablosu için SDK/sunucu bağlantısı bulunmaz; bu sürüm gelir elde etmeye hazır diye sunulmamalı.
